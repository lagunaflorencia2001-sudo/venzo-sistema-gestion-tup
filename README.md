# Sistema Integral de Gestión de Ventas, Facturación y Control de Stock - Venzo

## Descripción del Sistema
El presente proyecto consiste en el desarrollo e implementación de un sistema web integral para la empresa **Venzo** (dedicada al ensamblaje, distribución mayorista y venta minorista de bicicletas y repuestos). 

La solución automatiza el circuito comercial unificando la facturación electrónica autorizada por AFIP con el descuento en tiempo real del inventario disponible. Esto optimiza los tiempos de respuesta comercial a menos de 5 segundos por transacción y elimina discrepancias en el stock entre las áreas de ventas y el taller de ensamblaje.
